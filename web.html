Integración de Speakers — LABITCONF 2026
Guía para el equipo de desarrollo web. El listado de speakers vive en Google Sheets y se sirve vía un endpoint público de Google Apps Script (GAS). No requiere autenticación.
ENDPOINT
Hacer un GET a esta URL devuelve todos los speakers en formato JSON:
https://script.google.com/macros/s/AKfycbwe2LgPxVzFFto-fsQl0gSng2rgzbRSroALHOra43wK2QhlJZ_s-1xKHyv9An_g1ZA/exec?action=get_data&sheet=Speakers&key=BTC/2026
RESPUESTA JSON
El campo data contiene un array de arrays. La primera fila es el encabezado. Ejemplo:
{ "ok": true, "sheet": "Speakers", "data": [ ["postulacion_num", "nombre", "apellido", "confname", ...], // fila 0 = header [42, "Satoshi", "Nakamoto", "Satoshi N", ...], // fila 1 = primer speaker ... ] }
CAMPOS DISPONIBLES (índice → nombre)
Cada speaker es un array. Los campos relevantes para la web son:

EJEMPLO DE INTEGRACIÓN (JavaScript)
const GAS_URL = 'https://script.google.com/macros/s/AKfycbwe2LgPxVzFFto-fsQl0gSng2rgzbRSroALHOra43wK2QhlJZ_s-1xKHyv9An_g1ZA/exec'; async function getSpeakers() { const res = await fetch(`${GAS_URL}?action=get_data&sheet=Speakers&key=BTC/2026`); const json = await res.json(); if (!json.ok) throw new Error('Error al cargar speakers'); // Saltar fila 0 (header), mapear a objetos return json.data.slice(1).map(r => ({ id: r[0], nombre: r[3] || `${r[1]} ${r[2]}`.trim(), // confname o nombre+apellido cargo: r[5], pais: r[6], foto: r[10], linkedin: r[14], x: r[15] ? `https://x.com/${r[15].replace(/^@/,'')}` : '', instagram: r[16] ? `https://instagram.com/${r[16].replace(/^@/,'')}` : '', website: r[9], bio: r[21], estado: r[31], web_order: r[40] ? parseInt(r[40], 10) : null, // orden en web })).filter(s => s.nombre) .sort((a, b) => { const an = a.web_order, bn = b.web_order; if (an && bn) return an - bn; if (an) return -1; if (bn) return 1; return (Number(a.id)||0) - (Number(b.id)||0); }); } // Uso: getSpeakers().then(speakers => { console.log(speakers); // array listo para renderizar });
NOTAS IMPORTANTES
Orden en web: Cada speaker tiene un campo #WEB (orden) en el panel admin (columna 40 del sheet). Los speakers con ese número asignado aparecen primero, ordenados de menor a mayor. Los que no tienen número asignado van al final, ordenados por su número de postulación.
Fotos: Las URLs de foto son de Google Drive. Funcionan directamente en <img src="...">. Para mejor rendimiento, recomendamos descargarlas y servir desde el CDN propio en producción.
CORS: El endpoint de GAS devuelve cabeceras CORS abiertas (Access-Control-Allow-Origin: *). El fetch funciona desde cualquier origen.
Caché recomendada: El endpoint puede tardar 5-15 segundos en responder (Google Sheets). Cachear el resultado por 10-30 minutos en el servidor o en el cliente con localStorage.
Filtrar por estado: Para mostrar solo los speakers confirmados en la web, filtrar por r[31] === 'confirmado' (o el valor que defina LABITCONF).
